# Exports PNG des diagrammes

Dans Lucidchart : **Fichier → Télécharger → PNG** (haute résolution, fond blanc).
Déposer ici les cinq fichiers avec exactement ces noms :

| Fichier | Diagramme |
|---|---|
| `01-cas-utilisation.png` | Cas d'utilisation |
| `02-classes.png` | Classes |
| `03-activites.png` | Activités |
| `04-composants.png` | Composants en couches |
| `05-sequences.png` | Séquences |

Ne référencer ces images dans les documents qu'une fois les fichiers réellement présents.
